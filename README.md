# 💡 為什麼要用 RFM 分析？
RFM 常用於顧客分群，但套用在產品營運上一樣強大：

R (Recency) 最近售出時間：產品最近一次被購買是多久前？（評估熱度與活躍度）

F (Frequency) 購買頻率：產品被回購或下單的次數有多頻繁？（評估黏著度）

M (Monetary) 累積銷售額：產品帶來了多少營收貢獻？（評估價值核心）

透過演算法將產品自動分群，你一眼就能找出：

⭐ 明星爆款：高頻率、高金額、近期熱銷

💤 沉睡產品：金額貢獻高，但最近無人問津

📦 平價高頻消耗品：金額雖低，但維持穩定現金流

# 🛠️ 工具協作
- Google AI Studio：擔任你的 AI 程式助教，快速生成與調整資料處理邏輯、解讀報表意涵。

- Google Colab：完全不需在本地安裝環境，點開瀏覽器即可執行 Python。

- Scikit-Learn：執行特徵標準化（StandardScaler）與 K-Means 聚類。

- Seaborn / Matplotlib：生成直覺且美觀的多維成對散布圖。
